# Belt & Road Study and Employment Database / 一带一路留学就业数据库

[Back to portfolio / 返回作品集](../../README.md)

## Project / 项目

EN: An educational information platform bringing together country, university, major, cost and employment-sector information. Built as a Next.js and TypeScript application with Supabase integration.

中文：将国家、院校、专业、留学预算与行业就业信息整合为可检索的教育信息平台，基于Next.js、TypeScript与Supabase开发。

## Demonstrated scope / 工程内容

- Country, city, university and major directories / 国家、城市、院校、专业目录
- University comparison and cost-calculation pages / 院校对比与费用测算页面
- Internal CMS and leads-management routes / 内容管理与线索管理路由
- SEO, sitemap and structured content / 搜索优化、站点地图与结构化内容
- Supabase database schema and migration scripts / 数据表结构及迁移脚本

## Potential reuse / 定制开发参考

EN: Educational directories, searchable information portals, advisory-service websites and lightweight CMS workflows. Client data, source licensing and permissions require independent evaluation.

中文：适用于教育资料库、院校查询平台、咨询服务网站和轻量内容管理系统。新项目须独立评估数据来源、授权和权限。

## Verification limits / 验证边界

Historical deployment documents report a Vercel-hosted website. A June 2026 audit also recorded Supabase connectivity issues affecting lead database writes and admin retrieval. Current production availability and data accuracy have not been independently revalidated.

历史文档记录过Vercel部署；2026年6月审计同时指出Supabase连接异常影响线索数据库写入与后台查询。当前线上状态及数据准确性尚未独立复验。

No private leads, database records, secrets or production credentials are disclosed. / 本公开案例不包含私人线索、数据库记录、密钥或生产凭据。
