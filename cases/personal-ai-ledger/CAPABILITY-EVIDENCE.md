# 能力与证据边界

| 能力 | 实现及本轮证据 | 展示用语 |
|---|---|---|
| 默认CNY、明确MYR优先 | 合成测试覆盖parser→模拟表单→Worker→SQLite→finance | 已实现，自动化验证 |
| 跨币种 | MYR10.00 / CNY16.50纯虚构样例；保存原币和扣款，统计16.50一次；浏览器详情显示一致 | 已实现并验证该测试链路 |
| 重复入账 | 精确流水号、服务商别名、人工确认不同交易、并发和重放测试 | 疑似重复检测，不承诺识别所有重复 |
| 图片上传 | 鉴权、类型/尺寸/4MiB、TTL、一次领取、清理、频率限制 | 接口自动化通过 |
| 浏览器OCR | 现有Tesseract与中英模型；本轮合成图片只测试传输，不评估OCR准确率 | 已实现，准确率/设备性能待专项验收 |
| 系统听写/快捷指令 | 现有入口及教程；本轮无真实iPhone访问 | 已接入，完整实机流程待验证 |
| 导入 | 合成XLSX/XLS/CSV和来源格式回归通过 | 支持已测格式，不能承诺所有版本 |
| 账本/报销/债务 | 已有代码及历史测试；本轮不改模型，也未重验所有业务路径 | 已实现；相应证据详见私人审查报告 |
| 页面演示 | 本地合成首页、详情、统计、钻取，浅/深色与窄屏 | 实际浏览器展示，非真实账本、非实机认证 |

源码销售、可安装快捷指令、公开托管财务演示和多用户服务暂不提供。不存在公开在线演示地址；私人生产网站不用于作品演示。
